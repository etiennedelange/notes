# Security

Notes reads and writes files on your disk, so a hole in it can matter.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's advisory form](https://github.com/etiennedelange/notes/security/advisories/new)
instead. Include the version, your platform and the steps to reproduce.

This is a one-person project, so there's no fixed response time. A
confirmed issue gets fixed in the next release, and the advisory is
published once that release is out.

## Supported versions

Only the latest release gets fixes.
